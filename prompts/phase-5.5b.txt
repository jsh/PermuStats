### 🏛️ The Architect's Decision: The "Inner Loop" First

We will tackle this in two steps. First, we fix the **Decomposer**, because that is the "heartbeat" of the engine—it's called for every single permutation, regardless of whether we are sampling or exhausting. Then, we implement **Welford's Algorithm** to stop the multiple iterations in the Analyzer.

### 📑 Code Block: The Decomposer Blueprint

Builder, here is the architectural sketch for the optimized inner loop. Use this as your guide:

```python
def decompose_cycles(permutation: list[int]) -> AnalysisResult:
    n = len(permutation)
    visited = [False] * (n + 1)
    cycles = []
    
    for i in range(1, n + 1):
        if not visited[i]:
            curr_cycle = []
            curr = i
            while not visited[curr]:
                visited[curr] = True
                curr_cycle.append(curr)
                curr = permutation[curr - 1] # 1-indexed adjustment
            cycles.append(curr_cycle)
            
    # Return the AnalysisResult directly here or via the Factory

```
